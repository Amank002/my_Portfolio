Aman Kumar — Personal Portfolio

A modern, responsive personal portfolio website built with React.js and Vite to showcase my skills, projects, certifications, experience, and resume.

🚀 Live Demo

["View Portfolio on Vercel" (YOUR-VERCEL-LINK)](https://my-portfolio-kappa-gray-vmkhqi4qwd.vercel.app/)

🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Tailwind CSS
- Framer Motion
- React Icons

✨ Features

- Responsive modern design
- Dark-themed UI
- About Me section
- Skills section
- Projects showcase
- Certifications & achievements
- Experience section
- Contact section
- Resume view and download
- Smooth scrolling navigation
- Animated UI elements

💻 Run Locally

Clone the repository:

git clone https://github.com/Amank002/my_Portfolio.git

Go to the project directory:

cd my_Portfolio

Install dependencies:

npm install

Start the development server:

npm run dev

Open the local URL shown in the terminal, usually:

http://localhost:5173/

📄 Resume

The resume is available directly from the portfolio through the View Resume and Download Resume buttons.
